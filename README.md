# MNIST Handwritten Digit Recognition

This repository contains my **MNIST Practical 1** work as part of my academic learning.

## Project Overview

The MNIST dataset is a collection of handwritten digit images from 0 to 9. This practical focuses on working with the MNIST dataset and understanding how handwritten digits can be analyzed and recognized using Python.

## Dataset

- **Dataset:** MNIST
- **Content:** Handwritten digit images (0–9)
- **Image Size:** 28 × 28 pixels
- **Image Type:** Grayscale

## Technologies Used

- Python
- Jupyter Notebook / Google Colab

## Notebook

The practical implementation and code are available in:

- [MNIST.ipynb](./MNIST.ipynb)

## How to Run

1. Open `MNIST.ipynb` in Google Colab or Jupyter Notebook.
2. Run the notebook cells sequentially.
3. Follow the outputs to understand the practical implementation.

## Objective

To explore the MNIST handwritten digit dataset and understand the basic process of handwritten digit recognition.
